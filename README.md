# GiftControl
## Descripción:

Sistema de gestión interna desarrollado para optimizar los procesos administrativos y productivos de la empresa Regalo de Gracia, la cual se dedica a la elaboración y venta de productos personalizados.


## Funcionalidades:

1. Consulta y selección de productos
2. Registro de las características de personalización
3. Selección de tecnicas, tamaños y servicio de diseño
4. Selección de empaque
5. Cálculo de costos de los regalos personalizados
6. Consulta y gestión del inventario

## Instrucciones para ejecutar el programa

1. Descargar o clonar el repositorio del proyecto.
2. Abrir su IDE de preferencia (que soporte Java).
3. Seleccionar Open y abrir la carpeta del proyecto.
4. Esperar a que el IDE cargue el proyecto y configure el JDK de Java.
5. Abrir la carpeta `src` y localizar el archivo `Main.java`.
6. Ejecutar el método `main` haciendo clic en el botón verde de ejecución junto al método, o haciendo clic derecho sobre `Main.java` y seleccionando **Run 'Main.main()'**.
7. Utilizar el menú que aparece en la consola para interactuar con el programa.

Requisitos: Un IDE y un JDK de Java compatible con el proyecto.
